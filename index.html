Jenis aplikasi
Format keluaran

APK adalah pilihan standar untuk dipasang langsung di Android. AAB digunakan untuk jalur distribusi tertentu dan tidak bisa dipasang langsung.

Pengaturan lanjutanFramework, versi, permission, SDK, signing, dan lainnya
Deteksi proyek & versi

Custom script: sertakan nexabuilder-build.sh di root proyek ZIP/Git untuk framework khusus. Script harus menaruh APK/AAB hasil build di folder output yang diberikan mesin.
